# 卡牌战斗与界面改版 v0.3

2026-09-24。用户要求以《Slay the Spire》《卡厄思梦境》为方向替换主要战斗，同时保留其他玩法。本实现采用抽牌、能量、敌人意图、局内构筑与装备专属牌；不移植参考游戏的角色、卡牌文案、数值或抽卡经济。

## 核心规则

- 每次出征重新建立10张基础牌 + 1张武器牌；影步词条额外加入1张影步牌。共14种原创牌。
- 每回合3能量，抽5张。速度每比12高3点，首回合额外抽1张，最多2张。手牌上限10。
- 攻击牌选择敌人，技能直接生效。攻击必定命中，移除战斗d100命中和2d6伤害；保留装备暴击率。
- 手牌在回合结束进入弃牌堆。抽牌堆空时用保存的随机数状态洗弃牌；消耗牌不回流。抽牌技能结算完才进入弃牌，不会抽到自身。
- 普通格挡在下回合开始清空；不落牌将剩余格挡多保留一个回合。敌方格挡在敌方行动时更新。
- 首战胜利三选一卡加入本局牌组，可跳过。最终战之后无无效选牌奖励。装备掉落、拾取、估值、提前撤离与死亡损失沿用原实现。
- 敌人意图公开：猛攻、连击、筑甲、蓄势、撕咬；攻击值是格挡前伤害。玩家可通过破韧削弱意图，或在其行动前击杀。

## 属性映射

| 原属性 | 卡牌版作用 |
|---|---|
| 攻击／固定破甲 | 攻击牌基础值、敌方护甲穿透 |
| 防御／敏捷 | 格挡牌加成：基础格挡 + 防御/3 + 敏捷/6（分别取整） |
| 生命 | 生存和燃志的支付条件 |
| 速度 | 首回合额外抽牌，最多2张 |
| 移动力 | 掠影／影步额外格挡与下一击增伤，无格子移动 |
| 暴击／暴伤 | 攻击触发概率和伤害倍率，预览同时显示普通值与暴击值 |
| 流血 | 攻击附加流血，每目标最多3层，每层独立持续2回合 |
| 韧性 | 玩家每15点最大韧性降低1点敌方流血层伤害，最低1；敌人韧性降至0后本次攻击伤害减半并恢复韧性 |
| 感知 | 原有事件d100检定 |
| 意志 | 原有事件d100检定、心刃牌无视护甲伤害 |
| 影步词条 | 出征牌组新增0费影步，消耗，格挡并强化下一击 |

普通伤害使用原平滑防御公式，易伤为1.5倍，蓄势增加下一次攻击倍率。攻击结算后清除蓄势。
破阵先造成伤害，再施加易伤和削韧，所以易伤不会强化施加它的同次攻击。
结束回合先弃牌；敌人先结算自身流血，活着才执行意图；最后结算玩家流血，再判断胜负。敌人流血不会被格挡抵挡。无属性相克。

## UI与操作

- 营地分出征、仓库、牌组三页。出征强调场景、路线与单一主要操作；仓库保留格子管理；牌组展示当前装备所提供的出征牌。
- 战斗采用独立舞台、角色与敌人、顶部意图、底部手牌。行囊和记录按需打开，避免常驻仓库占用战斗空间。
- 卡牌标示能量、名称、类别、效果；悬停高亮，选中描边；攻击目标显示数值预览；出牌闪光与伤害飘字。
- 1–9/0选牌，Esc取消，空格结束回合。手牌多时横向滚动。抽牌堆弹窗按卡牌ID排序，不泄露牌序。
- 桌面1440×900验证；移动端未作为本轮目标。

## 存档与边界

存档v2包含所有牌区、局内牌组、能量、蓄势、意图、状态与随机数。v1升级保留物品、金币、进度与生命；进行中的格子战斗在当前房间重新开始。首次读取v1另存profile.json.v1备份。旧客户端不能读取v2，不能保证跨该改版回退。

本轮不增加角色抽卡、多人队伍、永久卡牌商店、独立卡牌强化或更多地城。装备升级、出售和库存管理保持原规则，尚未实现的附魔／鉴定／基础商店仍属于后续规划。
