# 原型范围与后续工作

本分支为第一份可玩规则原型，不代表完整MVP或成品美术。设计依据为
[评审后的v0.2策划](design-v0.2.md)。仓库实际由用户创建为Public，保持原设置。

## 本轮实现

- Godot 4.5.2标准版、GDScript、中文UI；网页与Windows导出配置。
- 8×6方格战场、障碍寻路、速度行动顺序、移动力、背面增伤。
- d100命中、2d6伤害、条件暴击率、平滑防御与固定破甲。
- 斩击、裂伤、直线突进、装备解锁的影步、防御与疗伤药。
- 流血持续伤害、削韧／失衡、敌人追踪近战AI。
- 两场战斗、中间感知／意志事件、拾取、提前撤离、死亡损失。
- 4种装备底材、4种原型稀有度、14种词条（其中1种解锁技能）。
- 6×5背包、10×8仓库；拖拽、旋转、装备替换、转移、出售确认。
- 武器金币强化至+3，装备词条实际参与下一次战斗。
- 完整探索状态自动保存，包括随机数状态；临时文件写入和备份恢复。

## 本轮刻意简化

- 成品二次元美术尚未制作；当前为代码绘制占位角色与符文风UI。
- 原型只有武器／护甲／饰品3个实装装备位，未实现设计中的8槽。
- 装备已鉴定，未加入未鉴定底材、完整鉴定服务或传说特效池。
- 强化暂只花金币；尚未做制作材料、附魔、拆解、基础商店、抽奖。
- 稀有度词条数暂为0/1/2/3，比正式策划压缩一档以验证UI与数据流程。
- 没有重量、安全格、容器嵌套、套装保存、搜索筛选、自动整理、赎回。
- 每次出发免费补给2瓶疗伤药，是原型便利设置，尚未接入补给经济。
- 失衡原型降低敌人下一击伤害，正式韧性规则仍需结合试玩调整。
- 没有完整魔法技能树、远程敌人、击退碰撞或自由探索地图。
- 只有本机／当前浏览器存档；没有云同步及存档导入／导出界面。
- 源码可运行不代表手机适配完成；先针对1440×900桌面验证。
- 未启用网站托管或改变GitHub Pages设置。Web构建包需要HTTP服务。

## 后续增补：主分支与启动器

首个原型已合并到main，按用户要求后续直接在主分支开发。新增Windows启动器，联网检查并自动安装
游戏版本，保留离线旧版、下载完整性检查和手动回退；主分支通过检查后发布GitHub Release。
自动更新不替代云存档，当前仍为本地保存。具体边界见[更新说明](updates.md)。

## 下一轮优先事项

1. 试玩确认命中、伤害、行动点与移动是否有取舍；调整战斗长度。
2. 产出原创二次元角色、四向战斗样板、场景与UI风格板。
3. 扩展鉴定、材料、附魔和估值提示，把拾取选择与长期成长连起来。
4. 扩充装备位、职业技能和敌人机制，再增加地城数量。

旧版220–440小时是此前方案估算，不作为这份实现的交付保证。
