# 当前原型范围

卡牌战斗刷宝原型，最新卡牌规则见[双资源构筑v0.5](card-economy-v0.5.md)，探索和营地经济沿用v0.4。

已实现：

- 17种原创卡牌、战意／灵纹双资源、免费基础牌、三张研习市场、购牌与精简、2种持续阵式、抽弃牌与消耗、敌人意图、格挡／流血／易伤／破韧。
- 装备属性、武器专属牌及影步词条与卡牌联动。
- 7×5随机迷雾地图，八邻格危险数字、零区展开、标记与侦察；普通战、精英、首领、宝箱、陷阱、祭坛、休息与入口撤离。
- 4种装备底材、4种稀有度、14种词条，武器／护甲／饰品3槽。
- 6×5背包、10×8仓库，拖拽／旋转／替换／转移、全部入库、自动整理、锁定防误卖和每格估值。
- 商店基础装备购买、背包与仓库物品出售确认；所有装备强化至+5；120金币抽奖、十次内稀有保底；独立附魔与重铸。
- 出征／仓库／商店／工坊／抽奖／牌组六分页；手牌与HUD直接叠在战斗场景上，扇形排列、悬停抬牌、点击或拖放出牌；抽牌／出牌／弃牌／命中／回合切换动画。
- 原创AI角色与遗迹图；敌人仍为代码绘制的符文造型。
- 存档v4与v1／v2／v3迁移；Windows自动更新启动器、离线游玩及完整性校验。

仍未实现：正式鉴定、材料、拆解、完整装备位、多角色队伍、更多地城、敌人插画、完整音效、云存档。交易当前为NPC商店，没有玩家交易市场。仓库没有重量／安全格／嵌套容器／筛选／赎回。

每次出征免费补给2瓶药；卡牌成长仅局内保留。抽奖只消耗游戏内金币，没有付费系统。网页包已导出，尚未上线公共托管。数值与地图节奏仍需试玩调整。
