# 迷雾探索、营地经济与手牌交互 v0.4

本轮落实用户新增需求；保留v0.3卡牌战斗与v0.2刷宝属性方向。不是复刻参考游戏的角色、美术或卡牌。

## 战斗界面

战斗背景覆盖整个战斗区域。上方HUD、下方扇形手牌与底部能量按钮都叠在同一场景中，不再将手牌放在单独的纯色面板里。角色和敌人位于场景上半部，为手牌留出清晰空间。卡牌使用真实控件，最多十张居中重叠，悬停抬起、放大并置顶；点击攻击牌后选目标，或直接拖至敌人。技能点击生效，也可拖到角色侧。保留数字键选牌与空格结束回合。最低窗口960×600等比缩放。新增依次飞入抽牌、出牌飞向目标、命中粒子与敌人震动、回合结束收牌和回合提示淡入淡出。动画期间短暂锁定操作，避免重复出牌或结束回合；选牌不重复播放抽牌动画。

## 探索规则

- 地图7×5，共35格，入口在左上，首领出口在右下。每次出征重新生成。
- 三场普通战、一场精英、首领，以及三处陷阱、三个宝箱、两个祭坛、一处休息点。
- 只能翻开与已清理路线四向相邻的格子；已清理路线可自动安全往返。
- 空地数字表示周围八格原始危险总数：战斗、精英、首领或陷阱。清理危险后数字不变，便于推理。
- 零危险空地自动展开邻接空地，不自动触发宝箱或危险。数字不是怪物伤害，也不保证相邻安全。
- 右键插旗防误触；侦察消耗次数查看邻接格内容，不触发事件，次数随感知提高，上限3。
- 陷阱使用感知d100检定，失败失去12生命但不会直接致死；休息恢复最多35生命；宝箱奖励25金币及装备。
- 祭坛保留感知／意志检定，每个祭坛只允许一次；战利品需要手动装入背包。
- 可返回入口提前撤离，或击败首领从出口撤离；未撤离的本局金币不结算，死亡损失沿用旧规则。

探索、战斗、装包和撤离共用一次出征状态。已清理格不重复发奖励；存档记录地图、当前位置、剩余侦察、牌区与随机数，关闭重开继续原进度。
