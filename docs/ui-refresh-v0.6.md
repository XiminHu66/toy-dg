# 界面与探索更新 v0.6

本轮保持v0.5卡牌与经济规则及v4存档格式，更新呈现与操作。

- 观测站营地主视觉、遗迹地图原创美术。统一深蓝、玉绿和旧金主题；环境漂浮微粒、场景缓动和面板过渡。
- 金币、本局收益、战意、灵纹、侦察、疗伤药、背包均有悬停说明；右上角手册以折叠条目解释来源、用途与重置时机。保留点击入口，支持无需悬停的阅读。
- 地图35个地点用原生绘制节点承载，显示已清理路径、可达前沿、当前位置、揭雾动画和进度。默认不显示未知房间类型；右键标记，侦察不触发事件，零危险区域仍按原规则自动展开。
- 地图下方显示悬停房间上下文；聚焦后支持方向键及回车。可安全返回入口，再撤离结算。
- 营地增加仓库、交易和工坊快捷入口；商店展示装备商品卡；工坊与寻宝的长规则可折叠。
- 仓库物品悬停估值和词条；拖放覆盖范围显示绿/红有效性，避免占用冲突；规则仍由原子操作验证。
- 交易等操作显示短暂反馈；寻宝保存结果后播放揭晓动画，期间锁定输入，避免连点重复扣款或重抽。

验证：5300项游戏规则/存档检查，34项更新器检查；UI冒烟覆盖35节点命中和隐藏信息、实际标记/侦察/进入信号、手册、抽奖防重复扣款、原有卡牌拖放和多分辨率布局。

本轮地图仍为单层7×5，暂未增加地形消耗、层间分支或新事件；地图移动光标为目的地过渡，已清理路径指示实际可通行连接。
