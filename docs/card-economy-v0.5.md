# 双资源、研习市场与构筑数值 v0.5

用户目标：参考《暗杀神》，使卡牌资源、战斗和数值更精简，同时保留运营、爽感和角色装备build。本版已实现下面的规则，替代v0.3的3能量卡牌规则；探索、营地交易仓管、抽奖附魔和动画沿用v0.4。

## 取舍与参考

参考发行方规则：https://stoneblade.com/pages/ascension-faq 。《暗杀神》的符文用于购入英雄／构筑，战力用于击败怪物；新牌通常入弃牌堆，资源通常不跨回合保留。本项目借鉴双资源分工、市场轮换、牌组精简和持续构筑。

本项目保留有生命值、敌人意图和装备属性的RPG战斗，直接伤害由攻击牌结算；不引入荣誉积分或第三种常规卡牌资源。为适应地下城，灵纹可跨战斗留到本次探索结束。市场缩为3张，避免六张公共市场占满战场。以下为本项目原创改编规则，不是暗杀神官方规则。

## 两种资源

| 资源 | 来源 | 使用和结算 |
| --- | --- | --- |
| 战意 | 每回合重置为2；折光斩、掠影、影步+1；燃志+2；熔炉从下回合起额外+1 | 基础牌0费，强力牌1–2费；回合内最多8。结束回合时最多3点转成每点2格挡，韧性达到20后每点3；随后清零 |
| 灵纹 | 每次真正进入一场战斗+2；研习牌+2并本场消耗 | 买牌3–5、精简3、刷新1；本次探索保留，上限12。与长期金币不互换 |

0费不代表没有选择：免费攻击会消耗已有的“下一击蓄势”，应先打基础攻击积累战意，再用掠影给大招蓄势。战意应投到斩杀、破韧或防御上；留力格挡只是未用资源的有限回收。

研习牌每场消耗、每场最多购牌2次、精简1次、刷新1次；拖战不会无限产灵纹。第6回合起敌人每次攻击每回合增加2伤害，已计入意图和伤害预览。

## 回合与牌区

1. 开始回合：2战意、5张牌；速度每超过12点中的6点，首回合多抽1张，上限额外2张。持续阵式触发。
2. 出牌、指定目标、研习市场可以穿插；一张牌结算后才可进行下一次操作。
3. 普通牌打出后进入“本回合已打出区”，当回合不能洗回；消耗牌进消耗区；阵式留在场上。
4. 回合结束：未用战意先转格挡；已打出牌与剩余手牌进入弃牌堆；敌人流血、行动，随后开启新回合。
5. 抽牌堆不足时洗弃牌堆；本场消耗和场上阵式不参与洗牌。新购牌进入弃牌堆，如果随后触发洗牌，也可能本回合抽到；已打出的牌仍不会循环。

基础9张（3折光斩、2守势、2研习、1灵光、1掠影）加1武器牌，共10张。影步装备额外加1张。最多18张，精简最低8张。撤离或失败结束本局牌组，下次出征重新构筑。

## 核心卡牌与数值

格挡基础加成为 `防御/4 + 敏捷/8`，分别向下取整；位移类格挡另加移动力。伤害仍受护甲、破甲、暴击影响；意志牌无视护甲。易伤从50%下调至25%，蓄势累计上限80%，减少乘法叠加失控。

| 卡牌 | 战意费 | 核心作用 |
| --- | ---: | --- |
| 折光斩 | 0 | 攻击×40%+1，获得1战意 |
| 守势 | 0 | 5+属性格挡加成 |
| 研习 | 0 | 2灵纹，本场消耗 |
| 灵光 | 0 | 抽2，本场消耗 |
| 掠影 | 0 | 2+属性+移动力格挡，1战意，下一击蓄势20%+移动力×3% |
| 断碑 | 2 | 长剑：攻击×150%+4，削韧6 |
| 鸦羽 | 1 | 短刃：攻击×65%+2，抽1 |
| 血线 / 收割 | 1 / 2 | 上流血，再以攻击×100%+2并追加10伤害收割 |
| 破阵 | 2 | 攻击×90%+4，削韧7，易伤2回合 |
| 交锋 / 不落 | 1 / 2 | 边攻边挡 / 大格挡并保留至下回合 |
| 心刃 | 2 | 攻击×25%+意志×28%+2，无视护甲 |
| 燃志 | 0 | 5生命换2战意，本场消耗，不可致死 |
| 影步 | 0 | 装备词条专属；格挡、1战意、蓄势，本场消耗 |
| 战意熔炉 | 0 | 打出后留场，从下回合起每回合额外1战意 |
| 守护矩阵 | 0 | 打出后留场，从下回合起每回合5格挡 |

阵式最多同时2个，同名不可重复；各阵式每局最多购入1张。阵式进入下一场战斗时重新回到牌组，需要重新抽到并打出。

## 运营与构筑

战斗顶部的“研习”打开3张市场牌；购入后立即补位，付费刷新保证新一组不含当前展示的牌。精简可以选择一张折光斩、守势或研习，系统从当前牌区中移除对应的一张。原来的免费战后三选一停止产生，避免战后选牌与市场两套成长界面重复；旧存档中未领取的奖励仍可领取。

| 构筑 | 属性与装备方向 | 关键卡 | 运营取舍 |
| --- | --- | --- | --- |
| 爆发剑 | 攻击、暴击、爆伤、破甲 | 断碑、破阵、燃志、熔炉 | 留产战意牌，先基础攻击再蓄势重击；别买太多2费牌 |
| 流血 | 流血词条、短刃、攻击 | 血线、鸦羽、收割 | 先铺流血再收割，抽牌提高组合出现率；避免只上状态不斩杀 |
| 壁垒反击 | 防御、敏捷、韧性 | 交锋、不落、矩阵 | 控制损血，剩余战意补挡；仍需保留击杀能力应对后期压力 |
| 灵刃 | 意志、速度与适量防御 | 心刃、灵光、熔炉 | 对高护甲有效；精简低效物理牌，但要保留足够产战意能力 |

感知继续服务于事件检定和迷雾侦察，不为每个属性再引入一条资源规则。装备稀有度本身不增加额外卡费机制，其价值仍来自底材、词条、强化和技能解锁。

例：开局2战意，先打两张折光斩后有4战意。若手里有断碑与破阵，可以都打、争取斩杀；也可只打破阵压低敌方威胁，留下2战意在敌方行动前转为4格挡。灵纹则决定买下一张核心牌，还是先删掉一张基础牌，提高后续抽牌质量。

## 平衡检查与边界

普通战敌人生命60/42，首领战125/40，精英首领生命90。敌人基础攻击也随免费出牌增加进行了上调。目标是普通遭遇约2–4回合、首领约4–6回合；具体并非硬性限制。

`tests/balance_probe.gd` 对普通与首领、五种固定配置各跑40个种子，共400场；策略只是按手牌顺序尝试合法牌，不购牌、不精简、不喝药，并非最优策略或玩家胜率估计。当前结果：

| 配置 | 普通平均回合 | 普通平均损血 | 首领平均回合 | 首领平均损血 |
| --- | ---: | ---: | ---: | ---: |
| 起始 | 3.30 | 3.05 | 5.45 | 9.18 |
| 攻击剑示例 | 2.25 | 3.13 | 3.30 | 9.90 |
| 流血示例 | 2.60 | 6.55 | 3.85 | 17.28 |
| 防御示例 | 3.35 | 1.63 | 5.35 | 4.85 |
| 意志示例 | 3.15 | 7.38 | 4.30 | 16.48 |

各配置均为满血单场，示例构筑分别加了不同属性和2张牌，未做装备预算等价控制，因此不能据此认定某流派更强。数据只用于检查时长、死循环和趋势；完整地城消耗、精简价值及高等级装备仍需试玩。低难度刻意保留较宽容的损血，未来难度梯度需独立设计。
